Syllabus Review

One row per point in the Edexcel GCSE Astronomy (1AS0) specification, Topics 1–13, for a teacher to check against the live site — built straight from the site's own data, the same way as the Syllabus Map, but flat (one row per point, lettered sub-codes included) and printable. The same report, as a document, is docs/syllabus-review.md in the repository.

Methodology

Depth
the spec's own know / understand / be able to tag for that point.
Page(s)
every page whose curriculum subtopic(s) declare that point's code; "not built" means none do.
Questions
practice questions anywhere on the site tagging a covering subtopic, counted only for a covered "be able to" point — shown as "–" for every other depth, and for a point not built yet.
Thin coverage
an automated, conservative flag on a covered point (never a judgement call — that's what the blank Teacher's verdict column is for), one or more of:
  1. an "understand" point where none of its covering pages are a verified diagram-first page;
  2. a "be able to" point with fewer than 2 practice questions site-wide;
  3. a point covered by exactly one page, where over a third of that page's own content lives behind a tap-to-reveal panel rather than always-visible prose.
